From microservices
to microcells.

Run a task when it is needed.
Save its progress so work can survive a crash.

A microcell, in this proposal by Yossi Eliaz, is one isolated run of one task: a shared workflow coordinator starts it, saves its result, and decides what happens next. The essay compares this with microservices, shows where Kubernetes and sandboxes fit, and gives a five-stage migration. It is a proposal, not a reference implementation.

STILL REQUIRED

Keep data correct. Know who can change it. Recover unfinished work.
The shared platform still needs scaling, monitoring, and recovery.
